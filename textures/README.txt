Planet textures go here (all optional).
  npm run textures        -> downloads 2K textures   (1080p video)
  npm run textures:4k     -> downloads 8K originals and downsizes to 4096 px (4K video)
Expected names: mercury.jpg venus.jpg earth.jpg earth_clouds.jpg mars.jpg jupiter.jpg saturn.jpg
                uranus.jpg neptune.jpg moon.jpg milkyway.jpg saturn_ring.png
Any file that is missing is replaced by a procedurally generated texture, so rendering never fails.
You can drop in your own images using these names. Solar System Scope textures are CC BY 4.0 (credit is shown in the video).
